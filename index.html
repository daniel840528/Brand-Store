HNB Store Strategy: Internal Alignment

Objective: Define Global Scalable Model

目標是建立一套能適應全球拓展的標準化系統。 利用中國供應鏈優勢，結合靈活的 UX 分區策略，實現輕量化快速落地。

🌏

Made in China, Local Assembly

供應鏈策略： 核心高工藝組件（展示桌、燈箱、金屬件）在中國集中生產，確保品質與成本。海外僅負責基礎硬裝與組裝。

🧠

UX Zoning Strategy

體驗動線： 空間不只是陳列，而是引導用戶旅程 (User Journey)。從吸引、試用、社交到購買，分區必須清晰且符合直覺。

📦

Lightweight & Demountable

落地策略： 追求「輕量化」。道具需具備 Flat-pack (扁平包裝) 特性，易於拆卸與搬運，降低物流與安裝門檻。

模塊化組件庫 (Component Kit)

Design for Disassembly: 每個組件都需具備獨立運輸與快速組裝能力。

Requirement: Flat-pack Ready

01. 可拓展中島 (Expandable Island)

Zone 1: Experience
  • • 結構：主櫃體 (1.2m) + 延伸櫃體 (1.2m)
  • • 功能：內藏充電/防盜線，替換式海報槽
  • • 材質：拉絲不銹鋼包邊 + 啞光檯面
適配: Type A (2.4m), Type D (1.2m)

02. 萬用牆面系統 (Universal Wall)

Zone 2: Display
  • • 結構：AA柱或 Slotwall 插槽背板
  • • 配件：通用掛鉤、層板、磁吸燈箱盒
  • • 調節：層板高度自由調節，適應不同產品尺寸
適配: Type A, Type B (主要展示面)

03. 樂高式收銀台 (Lego POS)

Zone 3: Service
  • • 模組 A：收銀主機位 (Core)
  • • 模組 B：轉角連接件 (Corner)
  • • 模組 C：前置陳列櫃 (Display front)
組合: Boutique (A+B+C), Kiosk (Only A)

04. 快閃式立柱 (Pop-up Totem)

Zone 2: Display (Kiosk Special)
  • • 需求：針對無牆面的 Kiosk 設計
  • • 功能：自立式高櫃，雙面展示
  • • 作用：定義空間邊界 (Invisible Wall)
適配: Type C, Type D (替代牆面)
💡

發光背板模塊 (Light Tile)

統一 600x600mm 發光方塊。可做海報、洞洞板或純裝飾。Boutique 牆面用 20 個，Kiosk 用 4 個。

🧲

磁吸式托盤 (Magnetic Tray)

桌面陳列底座磁吸化。新品上市時，店員無需工具即可瞬間替換佈局。

🔌

電力軌道層板 (Powered Shelf)

牆面立柱通電，層板扣上即亮。無需插拔線，大幅降低海外維護難度。
